# ⚡ Arpi Host

Publikasikan website kamu dalam detik! Cukup tempel kode HTML, dapatkan subdomain otomatis.

## Format Link
`web-name.project-name.arpihost.vercel.app`

## Cara Deploy ke Vercel

1. Upload semua file ke GitHub repo
2. Buka Vercel → Import repo
3. Buka **Storage** → Create Database → Pilih **KV** → Connect
4. Buka **Settings → Domains** → Tambahkan `*.arpihost.vercel.app`
5. Klik **Deploy** → Selesai! 🎉
